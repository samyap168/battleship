## Scores

Held back from higher only by HUD panels still being flat color fills under a nice corner-bracket ornament, and ship wake still being a generic smoke ribbon rather than a real hull wake.

**VFX Readability: 7/10 (+1).** The explosion is now an actual combustion event — dark smoke shell occluding an amber core with scattered debris (08_explosion) — a real fix, not a polish pass, over Round 1's flat gradient sphere. The drone swarm now reads as a directed mass thanks to a trailing wake and per-instance scale variance (07_swarm vs old 06_swarm). Capped below 8 because the far-zoom fleet-battle legibility problem from Round 1 (#10) has no comparable shot to verify it's fixed, and no storm/rain screenshot exists in this set to confirm the bloom clipping (#3 partial) was addressed at scale.

**UI/UX: 8/10 (+1).** Ability slots now show live cooldown/charge numbers and distinct iconography (crosshair, cloud, shield, sonar ping) instead of bare line glyphs, and every panel — score bar, ability bar, portrait, Armory, minimap — now shares a consistent gold corner-bracket motif that reads as "one game" rather than "one `<div>`" (02_early onward). The hex shield icon and hex shield VFX (09_shield) are a strong, on-brand addition. Still capped by panel *bodies* remaining flat navy/brown fills with no baked material detail, so the skin upgrade is ornament-deep, not surface-deep.

## Top 10 Fixes (ranked by impact × feasibility)

1. **Bake real material into HUD panel bodies.** The corner-bracket fix proved panels can look unified fast; now differentiate the *fill*. Canvas-bake a subtle brass-hairline/riveted-wood normal+AO texture per panel type once at load, sample it as a `THREE.CanvasTexture` on a `MeshBasicMaterial` (or as a CSS `background-image` data-URI for DOM-overlay HUDs), and reuse across score bar/ability bar/Armory/portrait so each keeps the same bracket motif but a different "forged" surface.
2. **Add a real shockwave ring to explosions.** 08_explosion nails the smoke/core layering but has no energy release read. Add one more additive plane: `float ring = smoothstep(0.0, 0.05, abs(dist - radius*time)) ; alpha *= (1.0-time)` driving a screen-space UV-distortion ring (`vUv += normalize(vUv-center) * ring * 0.02`) expanding over ~0.4s — cheap, reuses the existing explosion timer uniform.
3. **Soften the explosion core's clip point.** Core is still a hard-edged bright disc inside the new smoke. Feed the core sprite through ACES filmic tonemapping with threshold ~1.0 and a soft knee instead of clamping to white, so brightness rolls off into the smoke shell rather than cutting.
4. **Give the drone swarm one visually distinct leader drone.** Scale the front-most instance in the flock buffer by 1.4x and hue-shift it toward gold (`color.r += 0.2`), so 07_swarm reads "this is where they're headed," not just "mass drifting right."
5. **Radial cooldown-wipe shader on ability icons.** The numeric cooldown text is a good functional fix; layer a radial mask on top (`discard if atan(uv) > progress * TWO_PI`) tinted by resource type (kinetic=gold, utility=blue) so state reads at a glance without reading digits mid-combat.
6. **Velocity-driven ship wake normal map.** Coastline surf now looks great; ship wakes still don't match. Replace the flat smoke-trail plane behind each hull with a scrolling wake normal map whose UV offset is driven by `shipVelocity.length()`, additively blended into the water shader so faster ships visibly cut deeper water.
7. **Add a minimap radar-sweep + fog-of-war edge.** The gold frame and terrain tint are a good brand match; finish the metaphor with a slowly rotating alpha wedge (`angle = time * sweepSpeed; alpha = smoothstep(...)`) masked over an unexplored-fog layer, giving the minimap ambient motion instead of a static painted rectangle.
8. **Re-verify and, if needed, fix far-LOD ship silhouettes.** Round 1's #10 (ships collapse to colored dashes at full fleet zoom) has no surviving comparison shot — capture a wide fleet-battle screenshot again and, if still a plain dash, swap in the 3–4 baked ship-class silhouette icons proposed in Round 1.
9. **Confirm storm bloom/tonemap behaves at scale.** Storm weather was added since Round 1 but isn't represented in gallery2; take a dedicated storm screenshot and confirm the ACES/soft-knee fix from item 3 also tames the squall's lightning/spray bloom, since Round 1 flagged this as reading like an HDR bug.
10. **Cloud-shadow contrast pass.** The drifting cloud shadows read as soft light patches on water (02_early, 03_mid) but barely register against the ocean's own noise; darken shadow strength ~15% and add a slight blue-shift under shadow (`color *= vec3(0.85,0.88,0.95)`) so they read as weather, not rasterizer banding.

## Hero Moment: "The Reforging"

Every age-advance already swaps the ship model on `T` (visible in 03_mid/04_late's "press T to reforge your ship" prompt) — but it's an instant cut today. Turn it into the game's signature spectacle: on press, freeze input for ~1.2s, dolly the camera to a low three-quarter hero angle, and dissolve the old hull using the *existing* hex-shield shader as a mask (`discard if hexNoise(worldPos) > dissolveProgress`) while the new hull materializes from the same hex pattern inward-out in the target age's color grade. Ring the ship with 2–3 expanding energy rings (reuse the shockwave ring from fix #2), pop the age name in the existing serif kill-banner typography, and punch the per-age LUT transition as a half-second color-grade flash. Every piece — hex mask, shockwave ring, kill-banner type, per-age grade — already exists in the codebase; this is recombination, not new tech, and it converts a stat-menu click into the trailer moment.
